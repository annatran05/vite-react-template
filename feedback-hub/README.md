## 🎯 Overview

Feedback Hub is a modern, AI-powered feedback aggregation platform designed for product teams to collect, analyze, and act on user feedback from multiple sources. Built on Cloudflare's edge infrastructure, it delivers real-time insights with ultra-low latency and automatic categorization powered by Large Language Models.

### Key Highlights

- **Real-time AI Analysis**: Leverages Cloudflare Workers AI (Llama 3) for intelligent recommendation generation
- **Sentiment Detection**: Automatic emotion analysis using DistilBERT for prioritization
- **Multi-source Aggregation**: Centralizes feedback from GitHub, Discord, Email, Twitter, and Slack
- **Edge Computing**: Sub-50ms response times globally via Cloudflare's network
- **Zero Cold Starts**: Serverless architecture with instant scaling

---

### Data Flow

1. **Ingestion**: Feedback received via REST API or manual input
2. **AI Processing**: Sentiment analysis (DistilBERT) + categorization
3. **Intelligence Layer**: LLM generates recommendations (Llama 3)
4. **Storage**: Persisted to D1 with metadata
5. **Caching**: Hot data cached in KV for <10ms retrieval
6. **Presentation**: Served via edge workers globally

## 🛠 Tech Stack

### Frontend
- **Framework**: React 18.3 with TypeScript
- **Build Tool**: Vite 5.4
- **Styling**: CSS-in-JS with Cloudflare design tokens
- **State Management**: React Hooks (useState, useEffect)

### Backend
- **Runtime**: Cloudflare Workers (V8 Isolates)
- **Framework**: Hono (lightweight edge router)
- **API**: RESTful with JSON responses

### Database & Storage
- **Primary Database**: Cloudflare D1 (SQLite at the edge)
- **Cache Layer**: Cloudflare KV (distributed key-value store)
- **TTL Strategy**: 5 minutes for feedback, 2 minutes for analytics

### AI & ML
- **LLM**: `@cf/meta/llama-3-8b-instruct` (8B parameters)
- **Sentiment Model**: `@cf/huggingface/distilbert-sst-2-int8`
- **Inference**: Edge AI with Workers AI binding

### DevOps
- **Deployment**: Wrangler CLI
- **Version Control**: Git & GitHub
- **Monitoring**: Cloudflare Analytics + Logs

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ and npm
- Cloudflare account (free tier works)
- Wrangler CLI installed globally

```bash
npm install -g wrangler
wrangler login

## Installation
git clone https://github.com/annatran05/feedback-hub.git
cd feedback-hub

## Create D1 Database
npx wrangler d1 create feedback-db

## Copy your databaseID
{
  "d1_databases": [
    {
      "binding": "DB",
      "database_name": "feedback-db",
      "database_id": "YOUR_DATABASE_ID_HERE"
    }
  ]
}


##Create KV Namespace to wrangler.jsonc

npx wrangler kv namespace create "CACHE"

##Copy your cache id to wrangler.jsonc

{
  "kv_namespaces": [
    {
      "binding": "CACHE",
      "id": "YOUR_KV_ID_HERE"
    }
  ]
}


##Initialize Database schema
npx wrangler d1 execute feedback-db --file=./schema.sql


## Start Development Server
npm run dev
